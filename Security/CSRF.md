CSRF, or **Cross-Site Request Forgery**, is a web security vulnerability where an attacker tricks a user into performing unwanted actions on a website they are already logged into, without the user's knowledge. The attacker achieves this by manipulating the user's browser to send forged requests to the target website.

This is called a anti-forgery token in ASPNET. The attacker is thus unable to place a correct token in their requests to authenticate them
