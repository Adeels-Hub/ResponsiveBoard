API Gateway supports multiple authentication methods:
1️⃣ IAM Authentication – Uses AWS SigV4 for secure API calls.  
2️⃣ Cognito Authorizers – Manages user authentication via OAuth, JWT, etc.  
3️⃣ Lambda Authorizers – Custom auth logic (e.g., token validation, RBAC).  
4️⃣ API Keys & Usage Plans – Basic access control (not full authentication).
