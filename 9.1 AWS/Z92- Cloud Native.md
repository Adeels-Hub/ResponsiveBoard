**3. Networking & Content Delivery**
- **Amazon Route 53** – Scalable domain name service
- **Amazon API Gateway** – Managed API service for RESTful APIs
- **AWS App Mesh** – Service mesh for microservices networking
- **Amazon CloudFront** – Content delivery network (CDN)
- **AWS Global Accelerator** – Optimized traffic routing for low latency
**4. Security & Identity**
- **AWS IAM (Identity and Access Management)** – Access control and permissions
- **AWS Secrets Manager** – Secure storage for API keys and passwords
- **AWS Key Management Service (KMS)** – Managed encryption keys
- **AWS WAF (Web Application Firewall)** – Protects against web threats
