AWS Services — AZ, Region, Global Scope

Service Tied to AZ? Tied to Region? Global Service?
LambdaNoYesNo
You choose region; AWS manages AZ failover automatically.
ALBNoYesNo
Spans multiple AZs in a region for HA.
ELB (Classic/NLB)NoYesNo
Also spans multiple AZs when configured.
API GatewayNoYesNo
Region-level, with edge-optimized deployments available.
Global AcceleratorNoNoYes
Fully global; routes to closest AWS edge or region.
Route 53NoNoYes
DNS service—global by design.
SNSNoYesNo
Regional service; messages stay within a region.
SQSNoYesNo
Regional queues (you pick the region).
ECS - FargateNoYesNo
ECS service is regional; AWS places tasks in AZs.
ECS - EC2 Launch TypeYesYesNo
You must choose specific subnets (AZs) for the EC2 instances.
WAFNoYesYes (for CloudFront)
Regional with ALB/API Gateway; Global with CloudFront.

AWS Service Types vs Fault Tolerance

Service Type Fault Tolerance Examples
AZ-Scoped ❌ Low EC2 (single instance), EBS
Multi-AZ ✅ Medium RDS Multi-AZ, ALB, Aurora
Regional ✅✅ High Lambda, API Gateway, DynamoDB
Global ✅✅✅ Very High Route 53, IAM, Global Accelerator
