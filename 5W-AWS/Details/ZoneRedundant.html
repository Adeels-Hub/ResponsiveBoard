Service Tied to AZ? Tied to Region? Global Service? Notes
Lambda❌✅❌You choose region; AWS manages AZ failover automatically
ALB❌✅❌Spans multiple AZs in a region for HA
ELB (Classic/NLB)❌✅❌Also spans multiple AZs when configured
API Gateway❌✅❌Region-level, with edge-optimized deployments available
Global Accelerator❌❌✅Fully global; routes to closest AWS edge or region
Route 53❌❌✅DNS service—global by design
SNS❌✅❌Regional service; messages stay within a region
SQS❌✅❌Regional queues (you pick the region)
ECS - Fargate❌✅❌ECS service is regional; AWS places tasks in AZs
ECS - EC2 Launch Type✅✅❌You must choose specific subnets (AZs) for the EC2 instances
WAF❌✅✅ (for CloudFront)Regional with ALB/API Gateway; Global with CloudFront
