**5. Developer Tools & DevOps**
- **AWS CodeBuild** – Continuous integration
- **AWS CodeDeploy** – Automated deployments
- **AWS CodePipeline** – CI/CD automation
- **AWS CloudFormation** – Infrastructure as Code (IaC)
- **AWS CDK (Cloud Development Kit)** – Infrastructure automation with code
- **AWS X-Ray** – Tracing for distributed applications
 **6. Serverless & Event-Driven Services**
- **Amazon EventBridge** – Event bus for event-driven applications
- **Amazon SQS (Simple Queue Service)** – Asynchronous message queuing
- **Amazon SNS (Simple Notification Service)** – Pub/Sub messaging
- **AWS Step Functions** – Serverless workflow automation
