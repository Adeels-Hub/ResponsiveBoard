React Hooks, introduced in React 16.8, revolutionized functional components by enabling them to manage state, side effects, and more—without needing class components. This guide categorizes all core hooks into 8 groups, with clear use cases for each:

🧠 Categories of Hooks

State Management

  • useState: Basic local state
  • useReducer: Complex state logic
  • useSyncExternalStore: Sync external non-React stores

Effects

  • useEffect: Side effects post-render
  • useLayoutEffect: DOM measurement before paint
  • useInsertionEffect: Style injection (mainly for CSS-in-JS)

Refs

  • useRef: Persist values or reference DOM
  • useImperativeHandle: Expose instance methods to parents

Performance

  • useMemo: Cache computed values
  • useCallback: Cache function definitions

Context

  • useContext: Consume context data directly

Transitions

  • useTransition: Defer non-urgent state updates
  • useDeferredValue: Delay value updates for smoother UI

Utility Hooks

  • useDebugValue: Custom hook debugging
  • useId: Generate unique, stable IDs
