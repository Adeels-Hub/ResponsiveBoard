SPECTURA
1. **State Management Hooks**: Manage state within components.
2. **Effect Hooks**: Handle side effects and lifecycle events.
3. **Ref Hooks**: Access and manipulate DOM elements or mutable values.
4. **Performance Hooks**: Optimize rendering and computations.
5. **Context Hook**: Access context values in nested components.
6. **Transition Hooks**: Improve user experience with non-urgent updates.
7. **Utility/Random Hooks**: Utility hooks for specific use cases.
8. New React 19 Hooks: **Advanced** hooks introduced in React 19.
