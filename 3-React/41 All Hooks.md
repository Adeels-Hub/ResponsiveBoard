React hooks serve the purpose of enabling **state management** and **side effects handling** in **functional components** without needing to use class components. **Divided in 6 categories**
**State, life cycle management** :
       useState, useEffect, useReducer       
**Context, ReferenceManagement** :
	useContext, useRef, useImperativeHandle       
**Performance Optimization** :
       useMemo, useCallBack    
**Utility Hooks**:
       useLayoutEffect, useId, useDebugValue
