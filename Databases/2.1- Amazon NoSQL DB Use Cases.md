📘 **Amazon DocumentDB Global**
- **Multi-region Writes**: ❌ Not supported (single write region only)
- **Auto Failover**: ❌ Manual promotion required
- **Latency Optimized**: ✅ Yes (read-optimized with regional replicas)
- **Use When**:  
  • You need MongoDB compatibility  
  • Read scalability is more important than write availability  
  • You’re okay with managing failovers manually

 📘 **Amazon DynamoDB Global Tables**
- **Multi-region Writes**: ✅ Fully supported (multi-master)
- **Auto Failover**: ✅ Built-in
- **Latency Optimized**: ✅ Yes (writes/reads happen in nearest region)
- **Use When**:  
  • You need high availability and ultra-low latency at global scale  
  • You’re working with key-value or document-style access patterns  
  • You prefer serverless and auto-scaling behavior
