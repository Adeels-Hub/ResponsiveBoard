**SQL** Databases is one category which stores relational data
**NoSQL** (Not Only SQL) refers to a **broad category** of databases that are non-relational.
- Document Based - MongoDB, CosmosDB (Depends)
- KeyValue Based - Redis, DynamoDB
- Columnar Stores - Apache Cassandra, HBase
- Graph Databases - Neo4j

**DocumentDB** is a type of NoSQL database that stores data in document format (typically JSON or BSON).
**Examples**:    
**MongoDB** – Popular open-source document DB.
**Amazon DocumentDB** – A **MongoDB-compatible managed service** on AWS.
**Azure Cosmos DB (with API for MongoDB)** – Supports document model as one of its modes.

**Use Case:**
Use **DocumentDB** when your data is hierarchical or nested and you want flexibility in schema.    
Use **other NoSQL types** if your access patterns are better suited to key-value, graph traversal, or wide column stores.
